# StormMC website

Static site for the StormMC Minecraft server (Java + Bedrock, v26.2).

- Open `index.html` locally — no build step needed.
- Server details live in the `CONFIG` block at the top of `app.js`.
- Activate vote/community links by adding a `data-url` value in `index.html`.

Hosted with GitHub Pages at https://prime-cyber44.github.io/
